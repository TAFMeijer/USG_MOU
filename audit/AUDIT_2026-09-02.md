Scope: all code (Home, 4 pages, mou_lib, explorer.html/docs, analysis scripts), full
cell-level verification of `data/*.csv` against all **16** MoU PDFs in
`~/Library/CloudStorage/OneDrive-TheGlobalFund/Documents/RSSH/USG MoUs/` (9 dashboard
countries + 7 new FOIA releases), footnote-by-footnote checks of `mou_lib.BUDGET_FOOTNOTES`

(3) ingesting the 7 new countries (§E).

## C. Display / code bugs and stale UI text

**C1. BUG — Nigeria's 7-1-7 percentage indicators are drawn on the fixed 0–10 "days"
axis.** `pages/2_Country_programmatic_view.py` `indicator_chart`: the `is_717` branch
(scale domain [0,10], axis values [0,1,7,10]) takes precedence over `is_pct`. Nigeria's
four §1.3 indicators are percentages (Baseline 75 / 100 / 50 / 33) and plot far outside
the visible axis. Fix: check `is_pct` (or Unit == '%') before applying the 7-1-7 axis;
the day-based 7/1/7 charts for other countries keep the special axis. Note the new
countries keep 7-1-7 as day-commitments, so the split must be per-indicator, not
per-country.

**C2. Nigeria 7-1-7 targets exist but aren't charted.** Only Baseline rows are stored;
the 5-year targets ("≥95% nationwide", "sustain ≥90-100%", "≥90%", "≥85%") live in
'Unit / source note'. SECTION_BLURB promises "Nigeria also sets baselines and 5-year
targets". Encode the numeric part of the targets as Values (with the qualifier kept in
a column — see C6) so the charts show a line, not a lone point.

**C3. Stale line-style language after the stacked-panel refactor (commit ae57a87).**
`mou_lib.IMPUTED_CAPTION` ("dashed lines"), `BASELINE_CAPTION` ("dotted lines;
dash-dot"), both sidebar toggle help texts in `pages/1_Country_investment_view.py`
("Dashed lines", "dotted", "dash-dot") and the methodology page headers ("dashed
lines / sidebar toggle", "dotted lines / second toggle", "thin dotted line / third
toggle" for panels) reference line dashes that no longer exist — panels are stacked
areas that sum the bases. Rewrite to describe the toggles' effect on the summed bands.

**C4. Methodology describes the 2026 reference as USG-only; the code plots the
COMBINED 2026 level.** The "USG 2026-level reference" section says "overlay each panel
with the USG's 2026 level held flat" and the Cameroon example is USG-only math (it only
works because Cameroon's gov 2026 = 0). The sidebar help and on-page caption correctly
say COMBINED. Align the methodology text.

**C5. Summing-rules text is incomplete.** budget_series also includes Row type
`"Line item - outside headline total"` (Uganda's GoU $1M/yr MCH maintenance —
verified as the only such rows), but the methodology page ("Only rows with Row type =
'Line item' (plus existing-government rows)…") and the two table captions don't mention
it. Either document it or exclude those rows; if kept, note that Uganda's charted gov
total exceeds the MoU's own headline by that $1M/yr by design.

**C6. Standardise threshold/inequality targets.** Current conventions conflict:
Uganda ">95%" stored as 95 with a note; Ethiopia "<140"/"<20" stored as **blank** with
the bound in the note (so the 2030 point vanishes from the chart). New countries add
">90%" (Botswana), "~90%" (Eswatini). Recommend: store the numeric bound as Value +
add a `Qualifier` column ('>', '<', '~', '='), surface it in tooltips, and note the
convention on the methodology page.

**C7. Replace the `is_lower_better` keyword heuristic with a data column.** No live
misfire today (checked all 9 countries' indicators), but "cases"/"diagnos" will misfire
the moment a case-*finding* count indicator arrives (e.g. "# TB cases notified"), and
the caption "▼ lower is better" would then be wrong. Add a `Direction` column to
programmatic_tidy (populate once, mechanically) and keep the keyword fn only as a
fallback/for tests.

**C8. Dead "Co-investment benchmark" section.** `SECTION_ORDER`/`SECTION_BLURB` include
it but zero rows carry that Metric type. Either drop it or populate it (Kenya KES
ladder, Uganda/Cameroon/CIV DGHE pledges, Malawi Table 5.1 would fit).

**C9. `footnote_block` doesn't `md()`-escape `n['src']`.** Several src strings contain
"$35M"/"$1.35M"; a second "$" in the same block would trigger Streamlit's LaTeX math.
Escape src like text.

**C10. `AREA_NOTES`/`AREA_COLORS` carry "Commodities & HRH co-investment" but no data
